# Beyond text

The later HLC notes ask how the framework changes when the medium is an image, a sound, a video, or another kind of representation. They propose names such as Holographic Iconographic Cosmography and Holographic Multimodal Cosmography. The common question is what a representation makes available. A written description of a room, a photograph, and an audio recording preserve different aspects of the same setting. A model working with one or several of these inputs can be asked to compare patterns, but each input remains selective. ## Keep the translations visible

Imagine a written description of a crowded room used to generate an image, followed by a written analysis of that image. The final prose may contain details introduced during image generation rather than details from the original account. Those additions can be creatively useful, but they should not return to the original situation disguised as observations.

A simple record can preserve the initial description, the generated image, and the later interpretation as three distinct artifacts. Ask which details were supplied, which were inferred, and which were invented. This makes the cross-modal loop available for criticism.

The example also shows why a unified vocabulary should not flatten the media. A sentence can explicitly qualify a claim; an image may communicate certainty through visible detail without carrying an equivalent qualification. Moving between forms changes how uncertainty reaches the reader.
